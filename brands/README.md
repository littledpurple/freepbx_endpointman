# Свои пакеты брендов

Пакеты производителей, которых нет в репозитории provisioner.net. Ставятся через
**Advanced Settings → Manual Upload → Import Brand** (или `install_brand_package()`), модуль держит их в
`_ep_phone_modules/endpoint/master_local.json`.

    brands/build.sh dlink        # → dist/dlink-<время коммита>.tgz

`brand_id` — префикс id семейств и моделей в БД: только свободные, от 100.

## dlink — D-Link DPH-150S/SE h/w Fx (прошивка Fanvil, GE_1.00)

Проверено на DPH-150S, прошивка GE_1.00.

- Телефон просит один файл: MAC строчными без расширения (`GET /provisioning/p.php/84c9b2c4b0b7`, UA `WebClient`, HTTP/1.0).
  В автонастройке телефона: «Адрес сервера» `<АТС>/provisioning/p.php` (путь допускается), протокол HTTP.
- Формат — текст `<<VOIP CONFIG FILE>>Version:2.0NNN` … `<<END OF FILE>>`, CRLF, ключи выровнены до 19 символов
  (шаблон `dph150s/$mac` генерирует `make_template.py` — править там). Параметры `P1 …` и `SIPn …` телефон берёт
  только после строк `--Port Config--` / `--SIP Line List--`. Чего нет в файле — телефон оставляет как было.
- Файл применяется, только если версия выше текущей; после применения телефон сам перезагружается и скачивает
  файл снова (та же версия — не применяет). Номер ведёт модуль: `config_version_format` в `base.php`,
  `Provisioning::applyConfigVersion()`, растёт при изменении содержимого, начинается с 2.0100.
- Новый конфиг телефон берёт при загрузке и раз в N часов (`download_mode` 2, по умолчанию раз в час).
  SIP NOTIFY `check-sync` он подтверждает (200), но ничего не делает.
- Пароль админа телефона = Phone Admin Password модуля (`adminpass`; пустой — не трогаем). Умолчание модуля «123» —
  перед первым телефоном поставить нужный.
- Часовой пояс — индекс списка телефона, по часовому поясу модуля; SNTP — сервер времени модуля.
- Веб телефона: одна админ-сессия, выход — кнопка на LogOut.htm; брошенная сессия вешает веб до перезагрузки.
- Поля редактора: «пусто» = оставить как в телефоне (строки нет в файле). Без «пусто» по умолчанию:
  `Accept Any Call` 0 (звонки только через АТС) и `DHCP Option 66` 1. Гостевой пароль уходит только вместе
  с паролем админа (аккаунты — один список после `--MMI Account--`).
- У DPH-150S одна функциональная клавиша (F1), хотя в конфиге есть `Fkey1…11`. Быстрый набор: тип 1, значение — номер.
- Не работает на GE_1.00 (проверено, в шаблон не вошло): `Remote Control :0` не закрывает telnet (порт 23);
  удалённый syslog (`<AAA CONFIG MODULE>` + `MGR/SIP Trace Level`) пакетов не шлёт.
- `{if condition}` разбирает `base.php` бренда (`resolve_conditionals`): `endpoint_base::parse_conditionals()`
  после каждого верного условия выкидывает следующий блок `{if}` — ошибка общей библиотеки, касается и других брендов.
- Имена переменных не должны совпадать со статическими переменными библиотеки (`syslog_server`, `timezone`,
  `vlan_id`, `vlan_qos`, `local_port`, `network_time_server`, `srvip`, `mac`, `model`) — они подменяются до шаблона.
